# Contact_Management_project
# 📇 Contacts Management System

A robust desktop application built with **C# .NET Windows Forms** and **SQL Server**, designed following a clean **3-Tier Architecture** (Presentation Layer, Business Logic Layer, and Data Access Layer) to ensure separation of concerns, scalability, and maintainability.

---

## 🚀 Key Features

* **🔐 User Authentication:** Secure login interface with credential verification and failed attempt tracking.
* **📂 Full CRUD Operations:** Complete capability to Add, View, Update, and Delete contact records seamlessly.
* **🔍 Advanced Search & Filter:** Real-time search functionality with dynamic status updates, hit counters, and visual loading bars.
* **🖼️ Image Management:** Ability to assign, update, or remove profile images for individual contacts.
* **🖱️ Interactive UI & Context Menus:** Feature-rich DataGridViews supporting right-click context menus (Show information card, Edit, Delete, Add New).
* **🌐 Location & Data Integration:** Country mapping, birthdate selection via pickers, and organized address management.

---

## 🛠️ Tech Stack & Architecture

* **Language:** C#
* **Framework:** .NET Windows Forms (WinForms)
* **Database:** Microsoft SQL Server
* **Data Access:** ADO.NET (Parameterized queries for security against SQL injection)
* **Architecture:** 3-Tier Architecture (Presentation Layer ➔ Business Logic Layer ➔ Data Access Layer)
